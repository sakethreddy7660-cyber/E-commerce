# 🛍 Luxe Store

Luxe Store is a modern and responsive eCommerce web application built using HTML, CSS, and JavaScript.

This project features:

- Product listing
- Search functionality
- Shopping cart system
- Dynamic price calculation
- Responsive UI design

---

## Features

- 🔍 Product search functionality
- 🛒 Add to cart system
- ❌ Remove items from cart
- 💰 Automatic subtotal, tax, and total calculation
- 📱 Responsive design
- 🎨 Premium modern UI
- ⚡ Dynamic DOM manipulation using JavaScript

---

## Technologies Used

- HTML5
- CSS3

## JavaScript Functions

| Function | Description |
|----------|-------------|
| `displayProducts()` | Displays products dynamically |
| `addToCart()` | Adds product to cart |
| `removeFromCart()` | Removes product from cart |
| `updateCart()` | Updates cart UI and totals |
| `toggleCart()` | Shows/Hides shopping cart |
| `selectProduct()` | Selects searched product |
